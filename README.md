# Sitio web de Tu Nieto Favorito

Sitio estático publicado con GitHub Pages en https://tunietofavorito.com

- `index.html`: inicio
- `preguntas/`: preguntas frecuentes
- `terminos/`: Términos y Condiciones y Política de Privacidad
- `privacidad/`: redirige a la sección de datos de los términos
- `assets/`: estilos, script e imágenes
- `CNAME`: dominio propio (no borrar)

Los cambios se hacen sobre estos archivos; cada commit en `main` se publica solo en unos minutos.
